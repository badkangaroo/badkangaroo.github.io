Header Codec

The data arrangement and bit wise formatting for a reduced and compact arrangement of several different types to identify data sent through ribbit. The proposed total length of the header is 32 bits.

Data types

  • Emergency - 1 bit (boolean)
  • Timestamp - 31 bits
    • Year and Month - 10 bits (number)
    • Day - 5 bits (number)
    • Hour - 5 bits (number)
    • Minute - 6 bits (number)
    • Second - 5 bits (number)
  • Callsign - 48 bits (alphanumbit array)
    • [A-Z,1-9] - 6 bits (alphanumbit)
    • [A-Z,1-9] - 6 bits (alphanumbit)
    • [A-Z,1-9] - 6 bits (alphanumbit)
    • [A-Z,1-9] - 6 bits (alphanumbit)
    • [A-Z,1-9] - 6 bits (alphanumbit)
    • [A-Z,1-9] - 6 bits (alphanumbit)
    • [A-Z,1-9] - 6 bits (alphanumbit)
    • [A-Z,1-9] - 6 bits (alphanumbit)
  • Gridsquare - 28 bits (alphanumbit/nibble/alphabit array)
    • [A-Z ]Field - 5 bits (alphabit)
    • [A-Z ]Field - 5 bits (alphabit)
    • [0-9 ]Square - 4 bits (nibble)
    • [0-9 ]Square - 4 bits (nibble)
    • [A-Z ]Subsquare - 5 bits (alphabit)
    • [A-Z ]Subsquare - 5 bits (alphabit)

Emergency - 1 bit (boolean)

The emergency flag is a boolean value true or false.

Encoded Result: 0b0

Timestamp - 31 bits

An unusual format is used to keep track of the time a message is sent. The timing interval is set to every two seconds. The formatting is to reduce the use of bits by using only 10 bits for the month


Year+Month Encoded (10 bits): 0b0000000000



Day Encoded (5 bits): 0b00000



Hour Encoded (5 bits): 0b00000



Minute Encoded (6 bits): 0b000000



Second Encoded (5 bits): 0b00000


Timestamp Result (31 bits): 0b0000000000000000000000000000000

Callsign - 48 bits (alphanumbit array)

The callsign is an 8 character string encoded into 48 bits (6 bits per character).


Callsign Encoded (48 bits): 0b000000000000000000000000000000000000000000000000

Gridsquare - 28 bits (alphabit/nibble array)

The gridsquare is a 6 character location code (e.g., CM87uq) encoded into 28 bits.


Gridsquare Encoded (28 bits): 0b0000000000000000000000000000

Total Encoded Header - 108 bits

The total encoded header is 108 bits (1 + 31 + 48 + 28). It's a combination of the emergency, timestamp, callsign, and gridsquare.

0b

Decoded Header - 108 bits

The decoded header is 108 bits. It's a combination of the emergency, timestamp, callsign, and gridsquare.

0b

Delivered Header - 112 bits (14 bytes)

The header is actually returned by the decoder from the library as a series of bytes. So the last 4 bits of the last byte are 0s with the first 4 bits of the last byte being the last part of the Mainhead Gridsquare. That would look something like:

Delivered byte array 14 8bit (1Byte) values: [0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000, 0b00000000]

Recomposed header from bytes: 0b

The bytes are concatenated into a single 108 bit array which is then split into the 4 parts of the header.

Recomposed header from bytes:

Emergency bit: 0b0

Timestamp bits: 0b0000000000000000000000000000000

Callsign bits: 0b000000000000000000000000000000000000000000000000

Gridsquare bits: 0b0000000000000000000000000000

These are then decoded into the human readable header.

Emergency: false

Timestamp: 2026-01-01 00:00:00

Callsign: KN6FZY

Gridsquare: CM87uq
