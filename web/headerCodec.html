🐸 Ribbit Header Codec

Compact message header encoding/decoding system for amateur radio data transmission.
Watch data flow from human-readable → binary → bytes → binary → human-readable

Header Structure (128+ bits):
  • Callsign - 48 bits [8 chars × 6 bits alphanumbit]
  • Timestamp - 31 bits [Year/Month(10) + Day(5) + Hour(5) + Minute(6) + Second(5)]
  • Gridsquare - 28 bits [Letters(5+5) + Numbers(4+4) + Letters(5+5)]
  • Emergency - 1 bit (boolean flag)
  • NTP - 1 bit (boolean flag)
  • GPS - 1 bit (boolean flag)
  • Name Length - 8 bits [FirstName 4 bits + LastName 4 bits]
  • Message Length - 8 bits (0-240 bytes)
  • Message Type - 2 bits (0-3)
  • FirstName - Variable (0-75 bits, 5 bits per char, max 15)
  • LastName - Variable (0-75 bits, 5 bits per char, max 15)
  • Message - Variable (0-1920 bits, UTF-8 encoded)
  • ACK - Variable (acknowledgement array)
