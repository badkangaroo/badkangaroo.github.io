Chat: The default mode for Ribbit. It allows you to chat with other users in real-time.
QSO: A mode that allows automatic logging of contacts to and from other users.

The name of the operator. This will be displayed to other users. Character limit is 32 characters.

The callsign of the operator. This will be displayed to other users. Character limit is 8 characters.

GPS:

The current latitude and longitude of the operator. This will be displayed to other users. Click the button to update the GPS position, and to update the grid square.

The grid square of the operator. This will be displayed to other users.

Set color scheme of the application.

Select the microphone to use for receiving audio.

Select the speaker to use for transmitting audio. You will need to manually activate your transmitter to transmit the generated audio signal.

The time offset of the operator. Your time zone is set by the GPS coordinates. But you can modify it here if needed. +/- 12 hours. 0 means you'll see UTC time.

Save messages to the local device. This will allow you to view messages offline. Closing the app without saving will restore the messages on the next launch.

The number of messages saved to the local device.

Clear all messages from the local device. This will not delete the messages from other users.

Updates:

Check for updates from the server. This will check for updates and notify you if there is a new version.

Install the app on your device. This will allow you to use the app offline.

Configuration:

Restore the default configuration. This will restore all settings to the default values.

Save the current configuration. This will save the current configuration to the local device.

Load the saved configuration. This will load the saved configuration from the local device.

Logs:

Clear the messages log. This will clear the messages log from the local device.

Export the cardillio logs. This will export the cardillio logs to a file.

Export the ADIF logs. This will export the ADIF logs to a file.
